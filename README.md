# A S PLASTICS — Next.js 15 App Router

Modern web application for **A S Plastics** (Nashik, Maharashtra), converted to **Next.js 15 (App Router)** with React 19, TypeScript, and pure responsive Vanilla CSS.

---

## 🚀 Running the Project

```bash
# 1. Start the development server
npm run dev

# 2. Open in browser
http://localhost:3000

# 3. Build for production
npm run build

# 4. Run production server
npm start
```

---

## 📁 Project Architecture

```text
as-plastic/
├── app/
│   ├── globals.css         # Complete industrial design system (OKLCH tokens, responsive grid)
│   ├── layout.tsx          # Root layout with Manrope Google Font & LocalBusiness SEO Schema
│   └── page.tsx            # Complete landing page with interactive modals, FAQ accordion & WhatsApp flow
├── components/
│   └── ui/
│       ├── button.tsx      # Accessible button component with brand variants
│       └── dialog.tsx      # Accessible modal dialog for instant telephone enquiry
├── lib/
│   ├── brand.ts            # Centralized company data, phone numbers, address, WhatsApp URL builder
│   └── utils.ts            # Class name helper utility
├── public/
│   └── assets/             # Workshop photos, injection dies, logo, and tooling imagery
├── package.json            # Next.js 15, React 19, Lucide React
├── tsconfig.json           # TypeScript configuration with @/* alias
└── next.config.mjs         # Next.js framework configuration
```
